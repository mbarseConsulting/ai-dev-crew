# 📜 AI Template Engine

_Template de base pour vos projets d'IA._

## Vue d'ensemble

**AI Template Engine** est un template de démarrage pour construire des applications d'IA basées sur Claude AI. Ce projet fournit une architecture modulaire et extensible avec les meilleures pratiques pour développer rapidement vos propres projets d'IA.

Le template exploite le **Claude Code SDK** pour orchestrer des agents spécialisés et des compétences personnalisées, vous permettant de créer des workflows d'IA personnalisés, des agents intelligents et des applications interactives assistées par IA.
